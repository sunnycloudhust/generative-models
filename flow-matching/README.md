# Flow Matching

This folder is reserved for PyTorch experiments with flow matching, a generative modeling approach that learns a continuous vector field for transporting samples from a simple prior distribution to the data distribution.

The implementation is intended to be a small learning project inside the larger `generative-models` repository. It will prioritize readable components, simple training scripts, and easy-to-run experiments over production-level performance.

## Core Idea

Flow matching trains a neural network to predict the velocity field of a probability path between noise and data. After training, samples can be generated by solving an ordinary differential equation from the prior distribution toward the learned data distribution.

At a high level:

1. Sample data `x_1` from the dataset.
2. Sample noise `x_0` from a simple prior, such as a standard Gaussian.
3. Choose a time value `t` between 0 and 1.
4. Interpolate between `x_0` and `x_1` to obtain `x_t`.
5. Train a model `v_theta(x_t, t)` to match the target velocity.
6. Generate new samples by integrating the learned vector field.

## Setup

Install PyTorch in your Python environment:

```bash
pip install torch
```

For visualization or notebook experiments, these packages are also useful:

```bash
pip install matplotlib tqdm
```

## Usage

Once the implementation files are added, the expected workflow will be:

```bash
python3 train.py
python3 sample.py
```

If a config file is added, training will read experiment settings from:

```text
config.json
```

## Current Status

This module currently contains documentation only. The next step is to add a minimal flow matching implementation, starting with a simple 2D toy dataset before moving to image experiments.

## Roadmap

- Add a 2D toy dataset such as moons, circles, or Gaussian mixtures.
- Implement linear interpolation between prior samples and data samples.
- Train a small MLP to predict the velocity field.
- Add Euler or Runge-Kutta ODE sampling.
- Visualize learned trajectories and generated samples.
- Extend the experiment to image data with a small convolutional network.
